## 🧑‍💻 Sobre mí

Soy **Deiber José Vásquez Contreras**, desarrollador de software enfocado en construir soluciones web funcionales, mantenibles y orientadas a necesidades reales de negocio.

- **Especialidad**: sistemas administrativos, plataformas de gestión, APIs REST y diseño de bases de datos.
- **Enfoque actual**: arquitectura modular, desarrollo backend con TypeScript, infraestructura y buenas prácticas para crear software escalable.
- **Objetivo**: participar en proyectos donde pueda aportar de punta a punta, desde la interfaz y la lógica de negocio hasta la base de datos, la API y el despliegue.
- **Intereses**: herramientas administrativas, plataformas de gestión, sistemas empresariales y aplicaciones web modernas.
